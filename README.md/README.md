# AI Website Copy Generator for Local Businesses

## Business Chosen

QuizMaster Pro – Online Quiz Portal for Coaching Centers

## Objective

The goal of this project is to create a structured prompt system that generates high-quality website copy for a local business using AI tools.

This project demonstrates how Prompt Engineering can be used to generate professional website content that is clear, persuasive, and ready for publication.

## Tool Used

* ChatGPT

## Deliverables

This project includes:

* Homepage Copy
* Services Page Content
* CTA (Call-to-Action) Sections
* Tone Adaptation Examples
* Structured Prompt Framework

## Prompt Logic

The prompt collects business information such as:

* Business Name
* Business Type
* Location
* Target Audience
* Preferred Tone

Using these inputs, the AI generates:

1. Homepage Copy

   * Headline
   * Sub-headline
   * Introduction

2. Services Page Content

   * Service Name
   * What’s Included
   * Why Customers Should Choose It

3. CTA Sections

   * Contact CTA
   * Trust Building CTA
   * Urgency CTA
   * Location-Based CTA

4. Tone Adaptation

   * Friendly
   * Professional
   * Confident and Simple
