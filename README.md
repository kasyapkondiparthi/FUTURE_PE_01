# AI Website Copy Generator

## Project Overview

This project demonstrates how Prompt Engineering and AI can be used to generate professional website copy for local businesses.

The goal was to create a reusable prompt framework that produces website-ready content including homepage copy, service descriptions, call-to-action sections, and tone variations.

## Business Chosen

### QuizMaster Pro

QuizMaster Pro is an Online Quiz Portal designed for Coaching Centers and Educational Institutions.

The platform helps institutes:

* Conduct online quizzes
* Generate instant results
* Track student performance
* Reduce faculty workload
* Manage assessments digitally

## Objective

Develop a structured AI prompt system capable of generating:

* Homepage Copy
* Services Page Content
* CTA Sections
* Tone Adaptations
* Additional Website Pages

## Tool Used

* ChatGPT
